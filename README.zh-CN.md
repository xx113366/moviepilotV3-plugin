# MoviePilot V3 插件聚合库

仓库地址

```text
https://github.com/xx113366/moviepilotV3-plugin
```

在 MoviePilot V3 插件市场中选择“添加第三方仓库”，填写上面的地址后刷新列表即可。

当前插件包括：

- 绿联论坛签到
- 磁盘清理

插件使用独立目录和统一的 `package.v3.json` 清单，新增磁盘清理不会覆盖仓库中的其他插件。

磁盘清理完整说明见 [`plugins.v3/diskcleaner/USAGE.md`](plugins.v3/diskcleaner/USAGE.md)。首次使用建议开启演练模式，确认清理目标后再执行真实删除。
